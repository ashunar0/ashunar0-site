# OG 画像の配色メモ

記事を SNS に貼ったときのカード画像（`src/pages/og/[...slug].png.ts`）を作るときに
調べたこと。色を変えたくなったときに、また同じ回り道をしないための記録。

`index.html` をブラウザで開くと、参考にした 2 サイトの実物と候補が並ぶ。

```
open docs/og/index.html
```

候補を作り直すときは、プロジェクトルートから `node docs/og/gallery.mjs` を実行する。
`gallery.mjs` の `CANDIDATES` を書き換えれば別の案も出せる。

## 採用した値

背景は `accent`（朱・色相 6°）を起点に、色相を 335° まで 31° だけ回したグラデーション。
候補 `06.png` がそれにあたる。

| | 値 |
|---|---|
| グラデーション | `#ec968c` → `#f2b0cb`（135deg） |
| 額縁 | 40px |
| カードの角丸 | 16px |
| カード内の余白 | 48px |
| タイトル | 56px / bold / line-height 1.45 |
| アバター | 64px（円） |

## 参考にした 2 サイトの実測値

`sharp` で画素を読んで測ったもの。

| | 額縁 | 角丸 | カード内の余白（左/上） | 色相の幅 | 彩度 |
|---|---|---|---|---|---|
| Zenn | 38px | 11 | 53 / 63 | 56°（201°→257°） | 100% |
| azukiazusa.dev | 48px | 7 | 49 / 67 | 114°（216°→330°） | 43〜97% |
| このサイト | 40px | 10 | 51 / 65 | 31°（6°→335°） | 72% |

## 分かったこと

**グラデーションは額縁の幅でしか見えない。** 白いカードが画面の大半を占めるので、
角度を変えてもほとんど印象が変わらない。効くのは額縁の太さのほう。

**色相が離れた 2 色を混ぜると濁る。** 最初は `brand`（179°）と `accent`（6°）を両端に
置いたが、色相が 173° 離れていて、中間が彩度 0 の灰色を通るため濁って見えた
（`rejected-brand-to-accent.png`）。参考の 2 サイトはどちらも色相の幅が 56° と 114° に
収まっていて、道中ずっと彩度が保たれている。

**この 2 色は並べて使う設計ではない。** `brand` と `accent` が色相環の真裏どうしなのは、
片方が主役でもう片方が一点強調だから。面として隣り合わせると必ず喧嘩する。
グラデーションを作るならどちらか一方を起点にして、色相の近い色へ流す。

**`brand` をそのまま使うと重い。** 彩度は高いが明度が 36% と暗いため。
参考の色は彩度を保ったまま明度が 71〜87% ある。明るくするのが先。

**カードは一回り小さいほうが締まる。** 角丸 24px / カード内 padding 64px で作ったら
ぼてっとした。参考を測って 16px / 48px に落としたら収まった。

## 見送った案

`index.html` に残してある。Zenn（201〜257°）と azukiazusa.dev（216〜330°）の色相と
被らない範囲で選んだので、青系（水色・青・青紫）と紫ピンクは候補から外してある。

| | |
|---|---|
| 01〜03 | `brand` 起点（緑・黄緑）。サイトと地続きに見える |
| 04〜08 | `accent` 起点（オレンジ・ピンク・黄）。カードだけ暖色になる |
