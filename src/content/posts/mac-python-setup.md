次のコマンドを 1 つ実行すると、Mac に Python の開発環境がそろいます。ターミナル（`Command + Space` で「ターミナル」と入力して開けます）に貼り付けて、Enter を押してください。

```sh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Ashunar0/scripts/main/lab/setup.sh)"
```

始める前に GitHub のアカウントを作っておいてください。途中で手を動かす場面は 2 回あります。

- Homebrew がまだ入っていない Mac では、最初にログインパスワードを聞かれます。入力中の文字は画面に表示されませんが、そのまま打って Enter を押してください
- 最後に GitHub へのログインを求められます。画面に出る 8 桁のコードを控えて Enter を押すとブラウザが開くので、そこにコードを入力して承認してください

`環境構築が完了しました。` と表示されたら終わりです。途中で止まったときは、同じコマンドをもう一度実行してください。入っているものは飛ばして、止まったところから続きます。

## 入るもの

| 道具               | 役割                                                                         |
| ------------------ | ---------------------------------------------------------------------------- |
| Homebrew           | Mac にソフトをコマンドで入れる仕組み。下の道具はすべてこれを通して入れます   |
| Git                | コードの変更履歴を手元に記録するツール                                       |
| uv                 | Python 本体と、プロジェクトごとのライブラリをまとめて管理するツール          |
| Python 3.13        | uv が管理する Python。どのフォルダで使っても、既定でこの版になります         |
| GitHub CLI（`gh`） | GitHub へのログインやリポジトリの操作をコマンドで行う道具                    |
| VSCode             | コードを書くエディタ                                                         |

Python の版は、2025 年 10 月に出た 3.14 の 1 つ前にしています。研究で使うライブラリは、新しい版への対応が少し遅れることがあるからです。

Python のコードは `uv run` を通して実行してください。ターミナルで `python3` と打つと、Mac に最初から入っている Python が動きます。プロジェクトを作ってライブラリを入れ、実行するまでの流れは次のとおりです。

```sh
uv init --no-package my-project
cd my-project
uv add numpy
uv run main.py
```

`--no-package` を付けると、すぐ実行できる `main.py` が入った形でプロジェクトが作られます。付けないと、uv の版によっては `src/` 以下にパッケージを作る形になり、`main.py` ができません。

`uv add` で入れたライブラリはそのプロジェクトの中だけに入るので、別のプロジェクトとぶつかりません。

## VSCode の拡張と設定

拡張は 3 つ入れます。

| 拡張                | 役割                                                                     |
| ------------------- | ------------------------------------------------------------------------ |
| Python              | 補完やエラー表示、実行を担当します。入れると Pylance も一緒に入ります    |
| Ruff                | コードの整形と、書き方の誤りの指摘をまとめて行います                     |
| Material Icon Theme | ファイルの種類ごとにアイコンを付けて、一覧を見分けやすくします           |

設定（`settings.json`）は、Python のファイルを保存したときに Ruff で整形するようにしています。ほかには、行末の余計な空白を消す、ファイルの最後に改行を入れる、といった細かい整えを足しています。

元の設定は上書きされます。上書きする前に同じフォルダへ `settings.json.backup-日時` という名前で控えを残すので、戻したいときはそれを使ってください。場所は `~/Library/Application Support/Code/User/` です。

## GitHub との紐付け

最後のステップで GitHub にログインすると、この Mac から GitHub へ push できるようになります。パスワードやトークンを自分で用意する必要はありません。

あわせて、Git のコミットに記録される名前とメールアドレスも設定します。

- 名前は GitHub のユーザー名
- メールアドレスは GitHub に登録しているメインのアドレス

コミットを GitHub に push すると、このメールアドレスは誰でも見られる状態になります。公開したくない場合は、GitHub の設定にある `ID+ユーザー名@users.noreply.github.com` という形のアドレスに変えてください。

```sh
git config --global user.email "ID+ユーザー名@users.noreply.github.com"
```

ほかに、コミットメッセージを書く画面を VSCode で開くようにして、新しく作るリポジトリの最初のブランチ名を `main` にしています。
