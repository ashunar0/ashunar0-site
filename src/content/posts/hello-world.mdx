これは本文スタイルの確認用に、記事で使いそうな要素をひととおり並べたもの。行間や余白が読みやすい比率になっているかを見る。日本語は漢字と仮名が交互に来るぶん字面が詰まって見えるので、英語より広めの行間が要る。この段落は折り返しを確認できるくらいの長さにしてある。

## 見出しは h2 から

記事の中で一番大きい見出しがこれ。見出しの上は広く空けて、直後の本文とは近づけてある。近いものは仲間に見えるので、そのほうが「この見出しの説明だ」と伝わる。

段落を続けて置いた場合の間隔も確認する。ここが狭すぎると圧迫感が出るし、広すぎると話が繋がって見えない。

### 小見出しは h3

h2 との差が小さすぎると階層が伝わらず、大きすぎると分断される。**太字**と*斜体*、それから `const x = 1` のようなインラインコードもこの行に混ぜてある。文中の[リンクはこう見える](https://github.com/ashunar0)。

#### さらに下は h4

ここまで深くなることは少ないが、階層として成立しているかは見ておく。h3 との差はサイズ 2px と、見出しの上に空ける余白で付けている。

## コード

インラインは `pnpm build` のように書く。ブロックはこう。

```ts
import { getCollection, type CollectionEntry } from 'astro:content';

export type Post = CollectionEntry<'posts'>;

export async function getPublishedPosts(): Promise<Post[]> {
  const posts = await getCollection('posts', ({ data }) => !data.draft);
  return posts.sort((a, b) => b.data.pubDate.valueOf() - a.data.pubDate.valueOf());
}
```

横に長い行が来たときは折り返さず、ブロックの中だけを横スクロールさせる。以下はそれを確認するための一行。

```bash
pnpm dlx create-astro@latest my-site --template minimal --typescript strict --no-git --no-install --skip-houston
```
